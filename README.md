# MCInGameClicker (游戏内连点器 v1.0)

注入到 Minecraft 进程的**游戏内连点器**：按 **Insert** 呼出游戏内菜单，全部交互都在游戏里完成——不需要任何外部程序、不写共享内存、不走网络。

## 与旧项目 (AutoClicker / MCCombatStatusJni) 的关系

| 能力 | AutoClicker v2.9 (外部) | MCCombatStatusJni (DLL) | **本项目 (游戏内)** |
|---|---|---|---|
| 交互方式 | 桌面玻璃 UI | 无 UI (共享内存上报) | **游戏内菜单 (Insert)** |
| 连点执行位置 | 外部进程 PostMessage | 不连点 | **游戏进程内** |
| 共享内存 / UDP | 读共享内存 | 写共享内存 + UDP(已移除) | **全无** |
| 滚轮点 / 多倍点 | 有 | 无 | **删除 (需求)** |
| 线程 | 有 (点击线程) | 无 | **无** |
| 注入与钩子 | LoadLibrary + 钩子 | 同左 | **同左 (V65.1 对齐版)** |

## 功能

- **Insert** 呼出/关闭菜单（Esc 或点击菜单外空白也可快速关闭）
- 总开关、左键连点、右键连点（独立）
- 左/右键 CPS 独立**连续可调（5~50）**：**可见滑块条（轨道+填充+拇指）**鼠标按住
  左右滑动、点轨道跳值、滚轮、←→（按住自动重复）；**档位块 10/20/30/40 一键设值**
- **快捷键**（默认）：F8 总开关 / F6 左键 / F7 右键 / F9 保持；
  菜单中选中热键项按回车（或 ←→、或直接点击）进入绑定，按任意新键保存，Esc 取消；
  支持键盘与鼠标侧键/中键，冲突自动解绑旧键；三闸门也可绑定热键（默认无）；
  绑定与切换都有 **Toast 提示条** 反馈（与原连点器一致）
- 保持连点（无需按住鼠标；关闭时需按住左/右键才连点）
- 三个闸门（与 v2.9 同语义）：
  - **能攻击才点**：准星瞄准可攻击生物时左键才点
  - **能放置才点**：手持放置物（BlockItem/ItemBlock）时右键才点
  - **视角内才点**：光标隐藏（游戏视角）时连点，光标可见（背包/聊天/菜单）暂停
- 点击协议与外部版一致：`PostMessage` WM_LBUTTONDOWN/UP（DOWN/UP 交替），
  渲染帧内时间累加器保证平均 CPS 精确
- **菜单为独立分层悬浮窗 + 内存 DC 双缓存合成**（每帧一次 UpdateLayeredWindow
  交给 DWM 呈现），半透明、不闪烁
- **悬浮提示**：鼠标悬停菜单项即显示该项说明
- 设置自动保存到 `%APPDATA%\MCInGameClicker\settings.ini`

## 菜单操作

- `Insert` 呼出/关闭，`Esc` 关闭，**点击菜单外空白快速关闭**
- `↑` `↓` 选择菜单项
- `←` `→` 或 `回车`/`空格` 调整/开关；CPS 项按住自动重复连续滑动
- **CPS 项**：鼠标按住滑块左右**滑动**（2px=1 CPS）、点轨道跳值、点档位块
  10/20/30/40 一键设值、滚轮微调；←→ 按住自动重复连滑
- **热键项**：回车/←→ 进入绑定，按新键保存，Esc 取消
- 鼠标悬停任意项显示**悬浮提示**；直接点击菜单项切换
- 菜单打开时游戏输入被屏蔽（模态），连点暂停

## 架构（与参考实现对齐）

- 不创建任何线程、不 AttachCurrentThread、不创建任何 socket、不写共享内存
- 内联钩住 `gdi32!SwapBuffers`：覆盖 12 字节导出存根为绝对跳转
  （`mov rax,imm64; jmp rax`），真实函数从存根槽位读出
- 钩子内 `GetEnv()` 复用游戏渲染线程已有的 JNIEnv 解析 MC 状态，
  全部工作在渲染帧内分帧完成（每帧预算 8ms，采样 5ms 节流）
- `DllMain` 内把 DLL 从 PEB 模块三链表摘除（模块枚举不可见）
- 菜单为**独立分层悬浮窗**（WS_EX_LAYERED/TOPMOST/NOACTIVATE）：内存 DC
  32 位 DIB 双缓存合成（含逐像素 alpha），每帧一次 UpdateLayeredWindow，
  不碰游戏前缓冲、不闪烁
- 版本适配：171 张映射表（1.8.9~1.21.x，vanilla/forge/mojang/intermediary）

## 使用

1. 启动游戏，进入世界
2. 运行 `injector.exe`（或 `injector.exe -pid <PID>`）
3. 游戏内按 `Insert` 呼出菜单，开启总开关与左/右键连点
4. 默认需**按住**鼠标左/右键连点；菜单里开“保持连点”则无需按住

日志：`%TEMP%\MCInGameClicker.log`（关键事件；设置 `debugLogClicks=1` 可记录每次点击与状态变化）。

## 已知限制

- 若游戏跑在被改过的 JRE 上（例如 `jli.dll` 被 OpenZen 之类的保护组件替换的 JDK），
  该组件的加载器钩子可能把 DLL 导入直接解析到 gdi32 真实函数（绕过导出存根），
  导致存根钩子收不到帧。正常启动器（含网易版自带 JRE）不受影响；检测方法：
  注入后日志若长时间没有 `first-frame` 行，即为该情况。
- 冒烟测试请用干净 JDK：`pwsh -File test\smoke.ps1`（默认使用
  `C:\Program Files\Microsoft\jdk-11.0.16.101-hotspot\bin\java.exe`，可用
  `-Java <路径>` 覆盖）。测试用假客户端验证钩子/JNI 解析/连点全链路。

## 风险提示（重要）

与旧版一致：**注入行为本身**在部分自带客户端反作弊的环境（如网易版部分服务器
客户端自带反作弊）可能被检测并进黑屋。这与是否连点无关，是"进程被注入"这一事实
被客户端侧检测的结果。请自行评估风险，建议先用小号验证。

本项目无自动更新、无网络行为，设置与日志均在本机。
